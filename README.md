# trends-ia_p0-llm-flow

**P0 — Primeiro fluxo com LLM:** aplicação Python pequena, segura e reproduzível (Trends IA).

## Problema

Uma comerciante que atua com chaveiro automotivo (codificação de chaves) e
corretagem de imóveis recebe muitas mensagens de clientes no WhatsApp e perde
tempo decidindo o que é urgente, o que é orçamento de chave, o que é orçamento
de imóvel e o que é dúvida.

A aplicação recebe uma mensagem e classifica em uma das 5 categorias:
`orcamento_chave`, `orcamento_imovel`, `urgencia`, `duvida`, `outro` —
com justificativa curta.

**Justificativa da escolha do LLM:** ver [docs/relatorio.md](docs/relatorio.md).
